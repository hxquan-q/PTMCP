# PTMCP 仓库内低保真原型

版本：1.0-design · 日期：2026-10-23 · 状态：文本低保真，待走查；不是已实现 UI。

这些示意用于确认信息层级和交互。实际字段与动作见[页面规格](page-spec.md)，权限与API见[后端契约](../backend/api-spec.md)。方框中的按钮仅表示规划；界面不得显示无操作权按钮。

## 共用壳

```text
┌ PTMCP ─────────────────────── [管理视角 / 个人视角] [账号/退出] ┐
│ 管理导航             │ 页面标题 / 当前上下文                    │
│ 数据源               │ 说明 / 数据源ID / 平台 / 时区             │
│ 元数据与字典         │ 筛选区                       [主操作]     │
│ 组织与账号           │ ──────────────────────────────────────   │
│ 平台与客户端         │ 内容区 / 任务状态 / 表格                  │
│ 权限与委派           │                                          │
│ 审计                 │ 内联错误/空状态与requestId               │
│ ───────────          │                                          │
│ 我的字典 / 接入配置   │ [加载更多] / 已加载N条                    │
│ PAT / 我的授权 / 历史 │                                          │
└──────────────────────┴──────────────────────────────────────────┘
```

管理菜单根据功能码出现。窄屏收起导航，权限矩阵改分步，不把窄屏横向挤压当作完成响应式。

## WF-01 登录、账号安全与 AS 同意

```text
┌ 登录 PTMCP ──────────────────────────┐
│ 用户名 [__________________________]  │
│ 密码   [__________________________]  │
│ [登录]                               │
│ 错误/锁定说明 + requestId            │
└──────────────────────────────────────┘

┌ 授权给 <经核验客户端名> ──────────────┐
│ 平台 / clientId                      │
│ 申请范围: 目录 / 结构 / 查询          │
│ 回调目标: <经验证的精确URI>           │
│ 可续期策略/有效期: 按实际策略显示     │
│ [拒绝]                       [同意]  │
└──────────────────────────────────────┘
```

AS由authz宿主提供，独立Cookie；客户端描述纯文本。账号安全表单增加旧/新密码与确认值，提交前明确全部凭证失效。

│ 示例占位     │ MYSQL/...   │ ...  │ ...  │ ...      │ ...  │
└──────────────┴─────────────┴──────┴──────┴──────────┴──────┘

│ code(只读) / name                                  │
│ engine / host / port / databaseName / username      │

平台页复用列表/详情结构，页签为基础信息、Scope、客户端；Tier/proofMode与Scope分开，公开客户端没有secret输入。保存冲突显示新旧差异，不直接覆盖。

## WF-03 异步任务与快照

```text
Schema同步任务 <jobId>             [返回数据源]
状态: 执行中 | 开始时间 | 已处理对象数: N
总量未知时显示: 处理中…（不显示虚构百分比）
┌ 结果/异常 ────────────────────────────────────────┐
│ 快照ID / 完成时间 / 稳定错误码 / requestId         │
│ 成功后: [查看完整元数据]                           │
│ 失败时: [查看配置]，不发布部分成功快照             │
└──────────────────────────────────────────────────┘
```

页面离开停止轮询；恢复按jobId取最新状态。浏览器网络超时不擅自把服务端任务标为失败。

## WF-04 元数据与个人字典

```text
[平台(个人页)] [数据源] [database/schema] [表名关键字]
┌ 表物理路径/业务名 ┬ 表级说明 ┬ 可见状态               ┐
│ source/catalog/... │ ...      │ 可查询 / 仅目录可见    │
└────────────────────┴──────────┴────────────────────────┘

表详情 <物理四元组> / generation / snapshotVersion
业务名称与说明（管理页可编辑，个人页只读）
┌ 序号 ┬ 字段名 ┬ 类型 ┬ 可空 ┬ 键 ┬ 原注释 ┬ 业务说明 ┐
│ ...  │ ...    │ ...  │ ...  │ ...│ ...    │ ...      │
└──────┴────────┴──────┴──────┴────┴────────┴──────────┘
```

个人无READ时不请求/缓存列结构，详情区域改为权限说明；管理元数据需显式metadata:read。外键受限时仅说明“部分外键不可见”，不展示隐藏对象。

## WF-05 组织、用户、角色与委派

```text
┌ 部门树 ───────────┬ 当前部门成员 / 角色 ──────────────────┐
│ [展开] 部门根      │ [关键字] [状态]                [新建] │
│   子部门          │ 用户名/姓名/部门/角色/状态/操作         │
│                   │ 详情: 基本信息 / 角色 / 迁移 / 停用    │
└───────────────────┴───────────────────────────────────────┘
当前管理范围: 部门子树 ∩ 资源范围 ∩ 动作 ∩ 有效期
跨范围共享角色: 组织授权管理员只读；平台管理员持码可改
```

委派页由平台管理员创建，填写被委派人、部门根、资源、动作和期限；没有编辑端点，变更用撤销再新建。密码/角色/部门变化的影响用具体确认框显示。

## WF-06 授权矩阵（核心）

```text
┌ 主体 ─────────┬ 资源树 ─────────────┬ 规则与解释 ───────────────┐
│ 部门/角色/个人│ 数据源              │ META [ALLOW/DENY/无]       │
│ [搜索]        │  catalog(PG仅分组)  │ READ [ALLOW/DENY/无]       │
│ [选择主体]    │    schema(PG)       │ 继承 [ ]                  │
│               │      object         │ validFrom / validTo / 理由 │
│               │ [半选/已配规则]     │ 来源/现有DENY/资源版本     │
└───────────────┴─────────────────────┴────────────────────────────┘
待提交差异: 新增 N / 修改 N / 撤销 N（不是已生效）
预览: [目标用户] [平台] [时点:当前/模拟] [计算，不执行SQL]
结果: meta/read / reasonCodes / sourceGrantIds / nextBoundaryAt
                                                [提交已审阅变更]
```

半选只是配置差异。PG catalog分组没有授权勾选框；只提交DATASOURCE/NAMESPACE(catalog+schema)/OBJECT。READ ALLOW含META，META DENY阻断READ。模拟时点加明显标签；预览过期或切换主体后作废。每批最多100条，若逐条写入部分失败需逐条列出实际提交状态。

## WF-07 审计与个人历史

```text
[时间区间≤31天] [平台] [数据源(管理审计)] [工具] [result/verdict/error]
[管理员用户筛选]
时间 / 用户(仅管理) / 平台 / 目标 / 脱敏SQL / 状态 / 耗时 / requestId

┌ 调用详情 <requestId> ───────────────────────────────────┐
│ 身份/平台/目标/版本                                    │
│ result / verdict / error / UNKNOWN说明                 │
│ sqlMasked / fingerprint                                │
│ 阶段耗时 / rowsReturned / 截断原因 / 命中规则             │
│ [复制requestId] [原SQL解密: 独立权限+受控范围+理由]       │
└────────────────────────────────────────────────────────┘
```

个人历史没有用户筛选/解密/自动重试SQL。任何角色默认无原SQL解密权；解密须独立ptmcp:audit:decrypt、受控审计范围和理由，短期展示且关闭清空；页面不提供原始结果下载。

## WF-08 接入配置、PAT 与 OAuth 授权

```text
MCP接入配置  [平台] [客户端类型/实际版本]
状态: 待验证 / 已验证<实际版本> / 待配置域名
┌ 纯文本配置（OAuth通用配置无个人凭证） ─────────────────┐
│ 服务端生成/mcp地址；PAT用占位符                         │
└─────────────────────────────────────────────────────────┘
[复制配置]    [OAuth步骤] [创建PAT] [查看我的授权]

PAT列表: 名称 / 前缀 / 期限 / 状态 / 最近使用 / [撤销]
┌ 新PAT仅展示一次 ──────────────────────────────────────┐
│ <一次性完整值，示意稿不填写真实值>                     │
│ [明确复制]     已保存后关闭；关闭后不可取回             │
└───────────────────────────────────────────────────────┘

我的授权: 客户端/平台/签发/最近使用/绝对到期/状态/[撤销整族]
```

一次性PAT不写浏览器存储/日志/截图采集；响应丢失先确认已创建资源再撤销。凭证复制必须用户触发。没有真实部署参数时禁用配置复制，提示等待管理员发布。
