# OWASP ASVS 安全自查清单

基线：[ASVS 5.0.0 release](https://github.com/OWASP/ASVS/tree/5cf9b032440be53ce345ab3c130fda46ba1ce7a2)，日期：2026-10-23。本清单聚焦 V6 身份认证、V7 会话、V8 授权、V16 安全日志与错误处理。编号为 `v5.0.0-x.y.z`，不能混用 ASVS 4 的章节号。

这是一份选定条款的设计映射和待验证清单，不是完整 ASVS L2/L3 认证或达标声明。`NOT_RUN` 表示有设计但没有运行证据；`GAP` 表示当前设计尚有缺口。PASS 只能在实际实现、环境、构件和正反例结果具备后登记，N/A 必须给理由与评审。
