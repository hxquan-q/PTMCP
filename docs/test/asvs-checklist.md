# OWASP ASVS 安全自查清单

基线：[ASVS 5.0.0 release](https://github.com/OWASP/ASVS/tree/5cf9b032440be53ce345ab3c130fda46ba1ce7a2)，日期：2026-10-23。本清单聚焦 V6 身份认证、V7 会话、V8 授权、V16 安全日志与错误处理。编号为 `v5.0.0-x.y.z`，不能混用 ASVS 4 的章节号。

这是一份选定条款的设计映射和待验证清单，不是完整 ASVS L2/L3 认证或达标声明。`NOT_RUN` 表示有设计但没有运行证据；`GAP` 表示当前设计尚有缺口。PASS 只能在实际实现、环境、构件和正反例结果具备后登记，N/A 必须给理由与评审。

## 已知差距，不能写成通过

| 条款 | 当前差距 | 下一步 |

| 6.3.3 | 未定义所需 MFA/多机制组合或完整补偿论证 | 产品/安全决策后更新 PRD 与认证契约；本轮不伪造支持 |
| 7.1.1 / 7.1.2 / 7.3.1 | 有最长 8 小时，但闲置超时、并行登录数量与超限策略不完整 | T13 在实现前补风险依据、服务端过期和交互测试 |
| 7.5.1 | 敏感身份属性修改的完整重新认证策略未明 | T16 明确重认证/恢复流程，区分普通 CSRF 与身份再验证 |

| 16.4.3 | 未提供已验证的逻辑隔离日志分析/传输系统证据 | T20 验证独立收集、完整性、传输和告警；本地 outbox/WAL 不替代此项 |

每次安全变更更新受影响行，关联实际 TC/任务、版本/环境、命令、预期/实际、证据和评审者。结构校验或 Checkstyle/ESLint PASS 不能升级这里的状态。
