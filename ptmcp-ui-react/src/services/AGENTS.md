# 前端服务适配规则

本目录同时遵循[前端规则](../../AGENTS.md)；传输/会话以[前端指南](../../../docs/frontend/dev-guide.md)与 [API 契约](../../../docs/backend/api-spec.md)为准，接口变更按[合同](../../../docs/standards/api-change-template.md)同步。

- 复用 `http.ts` 的 CSRF、凭证、错误和会话过期处理；资源 API 不另开请求层。OAuth/MCP 响应不套管理 REST 适配器。
- ID 与 BIGINT/DECIMAL 保持字符串及精度；边界解析需在精度丢失前完成，不通过 `Number` 往返。REST/MCP 字段遵循各自协议，不对任意对象递归转换命名。
- 写操作、创建凭证与解密不自动重试；同一意图保留请求键，UNKNOWN 不换键重做。401/CSRF 恢复不自动重放原请求，秘密只保留必要内存生命周期。
- 个人门户按本人接口和访问上下文取数，不调用管理全局列表或用传入 userId 选择主体；菜单与本地权限缓存不能作为授权事实。

验证使用[传输、DTO、会话与幂等契约测试](../../tests)；合成响应与真实后端分别核对，不能默认为响应外壳和冲突状态已对齐。
