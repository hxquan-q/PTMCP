# 合成预览规则

本目录同时遵循[前端规则](../../AGENTS.md)；模式边界见[前端指南](../../../docs/frontend/dev-guide.md)，字段和动作见 [API 契约](../../../docs/backend/api-spec.md)与[页面规格](../../../docs/frontend/page-spec.md)。

- 合成数据只用于显式开发预览模式；真实模式请求失败不能回退到预览，也不从这里连接真实后端、数据库或载入真实凭据。
- 变更响应形状、校验、分页、版本或幂等时，与真实合同及已知差距一同核对；冲突、拒绝和未知结局显式返回，不能为页面演示统一成功。
- 种子保持合成、确定且可隔离；凭证创建遵循一次展示语义，不把完整秘密存入可重复列表或持久缓存。保留已有空、错误、冲突和慢响应场景的用途。

定向验证见[预览边界测试](../../tests/preview-server.test.ts)及相应资源契约测试；这些证据仅覆盖合成预览，不证明真实后端安全或业务通过。
