# persistence 模块规则

本模块同时遵循[后端规则](../AGENTS.md)；存储与锁顺序见[数据库合同](../../docs/backend/db-design.md)，WAL 见[审计合同](../../docs/backend/audit.md)。

- 安全变更保持业务行、版本/epoch 与事件的单一元库事务及固定锁顺序；事务回调不提交、关闭或外借连接，不在锁内调用业务库、Redis 或网络。
- 只有确认提交后才执行提交后动作；提交结果不明不得自动重放写命令或报告成功。唯一约束与 CAS 不用“先查再写”替代。
- WAL 确认必须覆盖对应持久化边界；解密/完整性失败按合同隔离，不删除后假装恢复。回放只补审计事件，不重新执行业务 SQL。

迁移和事务验证入口见 [README](README.md)与[本模块测试](src/test/java/local/ptmcp/persistence)；使用隔离元库和临时 WAL，结构测试、并发事务、崩溃恢复及部署卷持久性分别留证。
