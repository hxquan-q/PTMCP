# datasource 模块规则

本模块同时遵循[后端规则](../AGENTS.md)；连接、快照、只读执行与取消以[数据源合同](../../docs/backend/datasource.md)为准。

- 执行入口消费 guard 审批计划及其 final SQL；借连接前复核审批和权威状态，不开放任意 SQL 字符串的公共执行旁路。
- TEST/SYNC/QUERY 共用物理连接目的地与 TLS 策略；失败不得降级明文、跳过主机名校验或允许请求覆盖服务端信任配置。
- 取消返回不等于执行与驱动辅助任务已结束。复用连接前满足合同中的联合清理条件；终止或恢复不确定时淘汰，防止迟到取消影响新请求。

连接/取消变更按[真实数据库测试](src/test/java/local/ptmcp/datasource)覆盖受影响引擎与故障路径，不能以 mock 或正常查询替代 TLS、只读和复用边界证据。
