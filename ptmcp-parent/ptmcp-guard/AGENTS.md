# guard 模块规则

本模块同时遵循[后端规则](../AGENTS.md)；语法、作用域与审批顺序以 [SQL 守门](../../docs/backend/sql-guard.md)为准。

- guard 处理 SQL 与可信快照，不获取业务连接；新语法按白名单合同加入，解析失败或未知节点继续拒绝。
- `ApprovedQuery` 只能由完整管线产出；改写后仍须重解析并验证等价。保持构造边界，不新增从原始 SQL、DTO 或反序列化直接创建审批对象的入口。
- 审批对象不等于永久执行授权。执行前的身份、权威版本与审批有效期复核由执行接线保留，不能为了减少“重复校验”删除它们。

语法/绑定/改写变更从[本模块测试](src/test/java/local/ptmcp/guard)选双方言等价与拒绝反例；构建通过不证明拒绝路径没有借连接，接线证据须另取。
