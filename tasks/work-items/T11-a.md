## 目标与边界

来源/父任务或用户请求：[parallel-prompts-20261024](../parallel-prompts-20261024.md) B3，父任务 T11；[数据源设计](../../docs/backend/datasource.md) §4/§5/§6/§9、[总体方案](../../docs/总体方案.md) §8。

目标：在 `ptmcp-datasource` 的 `postgres` 包内落地 PostgreSQL 只读执行协议：干净连接→`setReadOnly(true)`/`setAutoCommit(false)`→显式 `BEGIN READ ONLY`→事务内 `SET LOCAL search_path TO pg_catalog`、`statement_timeout`、`lock_timeout`→逐项验证→执行→关闭结果/语句→rollback→恢复基线→归还；类型投影按正向白名单映射 logicalType，单格 4KiB 截断，行/响应预算整行丢弃；失败、超时、取消一律淘汰物理连接，对外只暴露已登记错误码。

不做项：不接 guard/ApprovedQuery/HTTP/MCP（C1）；不做 PG 连接池工厂与代际切换（本切片注入 `DataSource`，池注册表留给后续切片）；不做 Schema 同步（B5）；不做审计、租约、并发额度；不改 A6 MySQL 实现与断言；不改父 POM。

不变量：

- 模块外无任意 SQL 字符串执行入口：`PgReadOnlyRequest.of` 包内可见，唯一注释指定由 T07-c 之后的 ApprovedQuery 适配器调用；`PgReadOnlyExecutor` 不提供 `execute(String)`。
- 借出连接必须 `autoCommit=true`、`readOnly=false`、产品为 PostgreSQL；`SET LOCAL` 仅在显式只读事务内；配置后用 `pg_settings`/`current_setting` 验证 `pg_catalog`、精确毫秒值、`transaction_read_only=on`。
- 不注册驱动侧 `setQueryTimeout` 迟到取消定时器；超时由服务端 `statement_timeout` 产生。
- 配置/清理失败、执行中取消或超时一律 EVICTED，不把可能被污染的连接还给池。
- 未知类型即使 0 行也拒绝；domain 表列通过目录身份识别（见下）；错误消息只含错误码名，不含 SQL、驱动、主机或凭据。

## 实施与验证

### 生产代码

`ptmcp-parent/ptmcp-datasource/src/main/java/local/ptmcp/datasource/postgres/`：

```text
PgExecutorSettings    SQL 1..60000ms（默认 15000）/锁 1..SQL/清理 1..10000（默认 2000）
PgReadOnlyRequest     final class；包内 of(sql,maxRows)；MAX_ROWS=500、MAX_SQL_CHARS=65536、拒绝 NUL
PgReadOnlyResult      列/行/cellTruncations/两种 limit/trace；LogicalType+Encoding；行深拷贝
ColumnProjection      正向类型白名单、有界读取、UTF-8/二进制前缀、JSON 文本、truncation 元数据
PgReadOnlyExecutor    借连接→基线→配置→取消检查→执行/投影→清理或淘汰；无自由 SQL 公共入口
```

执行细节：

- 基线查询记录 `search_path`、`statement_timeout`、`lock_timeout`、`transaction_read_only`、`default_transaction_read_only`；清理时 rollback、恢复 autoCommit/readOnly、关闭连接，并再次比对基线，全部通过才 RETURNED。
- 读取使用 `TYPE_FORWARD_ONLY`/`CONCUR_READ_ONLY`、`fetchSize=100`、`maxRows`；先投影单元格，整行字节在追加前计算，超预算整行丢弃并置 `responseLimitReached`；达到 `maxRows` 置 `rowLimitReached`。
- 单元格：text/varchar/bpchar/name/json 经 `getCharacterStream` 读入 `char[4098]`，按码点截取 ≤4096 UTF-8 字节；bytea 读 ≤3072 字节后 Base64；int8/BigDecimal 输出字符串；float 的 NaN/∞ 输出字符串；date/time/timestamp(tz) 按契约格式；NULL 保留 null。
- 类型白名单：text/varchar/bpchar/name、int2/int4/int8、numeric、float4/float8、bool、date、time/timetz、timestamp、timestamptz、bytea、json/jsonb；其余（record、数组、range、domain、未知）拒绝 `RESULT_TYPE_UNSUPPORTED`。
- domain 识别：PG 18 在 RowDescription 中把 domain 表达式与 domain 表列都压平为基础类型 OID（探针：`pg_posint` 的目录 OID 为 16415，`SELECT NULL::public.pg_posint` 与 `SELECT value FROM public.pg_domain_cols` 的结果 OID 均为 23/int4），因此运行期用 pgJDBC Field 的 `tableOid`/`positionInTable` 取得结果列的真实基表列，在结果集关闭后执行一次 `pg_catalog.pg_attribute JOIN pg_catalog.pg_type` 查询，`typtype='d'` 即拒绝。表达式中的 domain CAST 没有基表身份，按 [数据源设计](../../docs/backend/datasource.md) §6 由 guard 的 OutputPlan/CAST 白名单在借连接前拒绝。
- 错误映射：取消标志/`CancelledQueryException`→`CLIENT_CANCELLED`；`SQLTimeoutException`/`57014`/`55P03`→`QUERY_TIMEOUT`；`25006`→`SQL_NOT_READONLY`；其余→`DRIVER_ERROR`；借池失败→`CONNECTION_POOL_UNAVAILABLE`。
- 配置失败：EVICTED + `DRIVER_ERROR`；清理失败：EVICTED + `CLEANUP_FAILED`；执行前已取消：`CLIENT_CANCELLED`，连接经清理后 RETURNED。

### 测试（真实 PostgreSQL 18.6 容器，固定 digest）

镜像 `postgres@sha256:edb0c08dc33befd0262ab3b5cf1c4f3f8cfd8b09e88c05b45adee29d6761ddb6`；PG 18 禁止 `pg_` 前缀超级用户名，测试用户为 `ptmcp_test`，库 `ptmcp_pg_test`；Hikari `maxPoolSize=1`，使连接复用/淘汰可见。`PgReadOnlyExecutorTest` 12 例：

- 只读事务拒绝 UPDATE：`SQL_NOT_READONLY`，原值未变；trace 为 CHECKOUT→CONFIGURE→EXECUTE→DRAIN→CLEAN→RETURN；随后原始 JDBC 连接基线为默认 search_path/0/off，下一请求成功且 generation 保留。
- `SET LOCAL` 作用域：业务查询内读到 `pg_catalog/on/15000/5000/off`；事务外执行 `SET LOCAL` 两值均不生效。
- 内置类型与精度：STRING/JSON/BINARY/BOOLEAN/INTEGER/DECIMAL/FLOAT/DATE/TIME/LOCAL_DATETIME/INSTANT 全覆盖；i8 与高精度 numeric 为字符串且精度保持；NULL 保留。
- 重复列名按 index 保留；Unicode 与 JSON 文本正确。
- 10MiB text/bytea/emoji：单格分别截到 4096/3072/4096 字节，无未配对代理项，3 条 truncation 元数据 `originalBytes=null`；JVM heap before=27,097,328 → peak=73,234,672（增长约 44MiB，<256MiB 断言）。
- 未知类型 0 行拒绝：`public.pg_domain_cols` 的 domain 列、composite、`integer[]` 全部 `RESULT_TYPE_UNSUPPORTED`。
- 行/响应预算：5 行取 2 行 `rowLimitReached`；260 字节预算只留 1 行并标 `responseLimitReached`；150 字节预算连首行都放不下，返回空行集但保留列并标 `responseLimitReached`。
- 注入配置失败：`DRIVER_ERROR`，EVICTED，abort/close 各 1 次，异常不含注入文本中的 password；下一请求成功。
- 注入 rollback 失败：`CLEANUP_FAILED`，EVICTED，close 1 次；下一请求成功。
- 执行前取消：`CLIENT_CANCELLED`，trace 终态 RETURNED。
- 200ms `statement_timeout` 执行 `pg_sleep(2)`：`QUERY_TIMEOUT`，EVICTED。
- 非法输入（空白/超长/NUL/maxRows 0/501）：拒绝且零次借连接。
