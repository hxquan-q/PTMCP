## 目标与边界

来源/父任务或用户请求：[parallel-prompts-20261024](../parallel-prompts-20261024.md) B4，父任务 T13；[认证契约](../../docs/backend/authentication.md) §4、[API 契约](../../docs/backend/api-spec.md) §9、ADR0003/0006。

目标：在 `ptmcp-authz` 落地独立授权服务器（Spring Security OAuth2 Authorization Server 7.1.2，版本走 Boot BOM）：AS 独立会话 `PTMCP_AS_SESSION`（HttpOnly/Secure 可配/SameSite=Lax/8h），与 admin 会话不共享；`/oauth2/authorize`（authorization_code，强制 S256、精确 redirect_uri、state、resource=audience）+ 最小同意页；`/oauth2/token` code 交换；`/.well-known/oauth-authorization-server` 与 `/oauth2/jwks`（只发公钥）；JDBC 仓储落 V3 表，code 消费为原子条件更新；不开放 implicit/password grant；PUBLIC 客户端不发 refresh token（refresh 扩展归 D1）。

不做项：不做 PUBLIC none refresh 轮换与 revoke（D1）；不做 DCR/CIMD/Tier1 证明（T14-a）；不做 gateway 侧 `/.well-known/oauth-protected-resource`（T19/T17 部署切片）；不改 admin/gateway POM 与共享契约；不接 guard/业务查询。

不变量：

- OAuth 默认关闭（`ptmcp.authz.oauth.enabled=false` 时 `OAuthDisabledSecurityConfiguration` 提供无会话直通链），启用后四条链：closed denyAll → AS endpointsMatcher → 登录/consent/健康 permitAll → 兜底 denyAll。
- redirect_uri 仅做注册表精确匹配，未注册 URI 永不成为重定向目标（包括 OAuth 错误重定向）；state/resource 在进入 SAS 错误重定向逻辑前校验。
- code 消费为条件 UPDATE（`code_consumed_at IS NULL` 前提），重放拒绝；code 指纹（SHA-256）落库，不存明文。
- JWT 载荷含 `platform_id`/`auth_version`/`family_id`(sid)/`display_name`，600s TTL，无 refresh token。
- 错误响应遵循 OAuth 标准：token 端点为 `application/json` 的 `{"error": ...}`，不套 REST 外壳、不 HTTP200 包装；authorize 端点无法构造错误重定向时由 SAS `sendError(400)` 失败封闭，绝不重定向。

## 实施与验证

### 生产代码

`ptmcp-parent/ptmcp-authz/src/main/java/local/ptmcp/authz/oauth/`（19 个类，均为本片新增）：

```text
OAuthSecurityConfiguration   四条过滤链；AS configurer 的 setter 全部置于 with() lambda 内
OAuthDisabledSecurityConfiguration  enabled=false 时 STATELESS 直通链
OAuthDataConfiguration       Hikari 元库池/JdbcTemplate/BCrypt 认证器/RSA JWKSource/JWT 生成器
OAuthProperties              enabled/issuer/audience 配置（enabled 默认 false）
AuthzDataSourceProperties    元库连接配置
PtmcpRegisteredClientRepository   V3 oauth2_registered_client → RegisteredClient（CSV 列编解码）
PtmcpOAuth2AuthorizationService   V3 oauth2_authorization 读写；state 列=服务端同意 state，
                             客户端 state 存 attributes JSON（ptmcp.authz.client_state）；
                             code 指纹与原子消费；CGLIB 代理（非 final + @Transactional）
PtmcpOAuth2AuthorizationConsentService  V3 oauth2_authorization_consent
AccountAuthenticationProvider / AccountAuthenticator / JdbcAccountAuthenticator / AsPrincipal /
AuthenticatedAccount   AS 独立登录（sys_user 登录名 + BCrypt 校验，不共享 admin 会话）
AuthorizationRequestPolicy   authorize 请求转换器：state/redirect_uri 非空、resource==audience、
                             客户端与 redirect 精确匹配；匿名请求放行给入口点去登录
OAuthPageController          /login 与 /oauth2/consent 服务端渲染页（CSP、转义、CSRF 隐藏域、no-store）
RsaJwkSourceFactory          PEM RSA 密钥 → JWKSource（jwks 只出公钥）
PtmcpJwtCustomizer           claims：iss/sub/client_id/platform_id/auth_version/family_id(sid)/scope/jti/iat/nbf/exp
OAuthAttributes              常量：family_id/auth_version/client_state/初始版本
OAuthStoreSupport            JSON/时间/CSV 工具
```

关键事实（依据 SAS 7.1.2 源码核对，非猜测）：

- `with(configurer, customizer)` 先设 builder 再跑 customizer，凡触碰 `getBuilder()` 的 setter 必须在 lambda 内。
- 同意流由 SAS 自生成同意 state（`state` 列存它作查找键），客户端原始 state 在 `OAuth2AuthorizationRequest` 属性内；同意后 `attributes.remove(STATE)`，因此客户端 state 必须单独持久化（本片以 attributes JSON 承载并在重建时回填），否则最终重定向 `state=null` 或返回服务端 state。
- `OAuth2Authorization.Builder.attribute(name, null)` 抛异常：family_id 等可空属性全部条件化。
- `RegisteredClient` 的 methods/grant_types/redirect_uris/scopes 列为逗号分隔 CSV；`oauth2_authorization.scopes` 为 JSON 列。
- 无 redirect 可用的 authorize 错误：SAS `sendErrorResponse` 对 `token==null || redirectUri 空` 走 `response.sendError(400)`（容器错误页），对合法 redirect 才重定向并带 `error`；这是 SAS 默认且符合 RFC 6749 §4.1.2.1 失败封闭要求。
- token 端点未知 grant：`OAuth2TokenEndpointFilter` 抛 `unsupported_grant_type` 并由 `OAuth2ErrorAuthenticationFailureHandler` 写标准 JSON。

### 测试（真实 MySQL 容器 + 真实 HTTP 会话）

镜像 `mysql@sha256:76f0358884cb92d9a086d24e5671c38048d3fef40f2588703d73eb55392d6b69`，UTC + utf8mb4_0900_bin，Flyway 复用 `db/ptmcp-migration` + 测试身份迁移 `V900__authz_test_identity.sql`；测试自实现 `HttpSession`（Cookie 罐、真实 302/表单跟随）。`OAuthAuthorizationCodeFlowTest` 11 例：

- 登录页硬化：CSP/no-store/转义，无 CSRF 的登录 POST 拒绝。
- code 全流程闭环：登录→PKCE(S256) authorize→同意页→同意→code→token 交换→RS256 验签（kid 匹配 JWKS）→claims 逐项断言（600s TTL、sid=UUID、scope）→库内 `family_id` 记录 1 条、code 指纹已消费。
- code 重放拒绝（invalid_grant，JSON）。
- verifier 不匹配拒绝且 code 不被消费（可再正确交换）。
- 非法 authorize 请求失败封闭：缺 state / redirect_uri 多字符与少字符 / 缺 resource / resource 错误 → 400、无 Location、无 code、响应不回显客户端 redirect_uri（SAS sendError 语义）。
- plain PKCE 拒绝（error 重定向 invalid_request，state 保持客户端原值）。
- 匿名 authorize → 登录页；登录后回到流程。
- implicit（response_type=token）与 password grant 拒绝；token 端点错误为标准 JSON `unsupported_grant_type`。
- PUBLIC 客户端不发 refresh token。
- 发现文档只声明已实现面（grant_types 仅 authorization_code；revocation/introspection/registration/par/device/userinfo/dpop 等字段不出现）；未实现端点（/oauth2/revoke 等 12 个路径）一律 403。
- JWKS 只有 `kty/kid/use/alg/n/e`，无私钥字段，kid 长度校验。
- 同意页：元数据转义（XSS 用例）、CSRF 隐藏域、拒绝同意不发 code 且向客户端回 `error=access_denied` + 客户端 state。

稳健性：Docker Desktop Windows 端口转发偶发丢首包（`Communications link failure`/`Connection timed out: getsockopt`），测试内直连统一走 3 次重试的 `connect` 助手。

## 结果与证据

GREEN（Java 21 / Enter-Dev，真实容器）：

```text
.\mvnw.cmd -B -ntp -pl ptmcp-authz spotless:apply
.\mvnw.cmd -B -ntp -pl ptmcp-authz -am verify -Dtest=OAuthAuthorizationCodeFlowTest,AuthzApplicationHttpStartupTest
```

结果：OAuthAuthorizationCodeFlowTest 11 tests + AuthzApplicationHttpStartupTest 2 tests（OAuth 关闭态启动），共 13 tests，0 failures / 0 errors / 0 skipped，`BUILD SUCCESS`。

偏差与处理：

- authorize 端点"失败封闭"类错误（缺 state/resource、redirect 不精确、response_type=token）实际为 SAS `sendError(400)` 容器错误页而非 JSON 体。按 RFC 6749 这类错误本就要求"告知资源所有者且不得重定向"，HTML 错误页合规；本片不改 SAS 失败处理器（避免复刻其重定向逻辑引入新风险），测试断言固化为失败封闭语义（400 + 无 Location + 不含 code/redirect）。token 端点错误保持标准 JSON。
- 同意 state 与客户端 state 分离是 SAS 设计使然：修复过程中补上客户端 state 的持久化与回填，否则同意完成后重定向 `state` 缺失/错值。
- 修复了页面控制器真实缺陷：同意页表单缺 `_csrf` 隐藏域，CSRF 开启时拒绝同意永远 403。

未执行项：PUBLIC refresh 轮换/revoke（D1）；gateway 侧 protected-resource 发现；双副本原子竞争与丢响应注入（M0 前扩展默认关闭，归 T13 后续切片）；生产 TLS 下 Secure Cookie 的端到端验证（`PTMCP_AS_COOKIE_SECURE` 本地关闭仅限联调）。
