## 目标与边界

来源/父任务或用户请求：[parallel-prompts-20261024](../parallel-prompts-20261024.md) C7（父 T15）；
[API 规格](../../docs/backend/api-spec.md) §4/§5、[数据源设计](../../docs/backend/datasource.md) §1/§2、
[安全架构](../../docs/architecture/security.md)。

实现管理面数据源 CRUD/连接测试/同步，以及基于已发布快照的元数据对象列表/详情与业务字典写入：

1. **数据源管理**（`ptmcp-admin` 包 `local.ptmcp.admin.datasource`）：创建/更新/停用/删除、
   列表（keyword/engine/status + 数字游标）、详情；凭据只写不读，AES-GCM 封存，
   响应仅 `credentialConfigured=true`；`configVersion` 作 ETag 与 If-Match。
   目的地校验在写入与每次连库前执行：仅 CIDR 白名单内可达（空白名单=全部拒绝）、
   拒绝 loopback/私网/链路本地/metadata/组播/未指定地址，DNS 解析全部地址逐一校验，
   协议固定 `VERIFY_FULL`，不接受任意 JDBC URL/驱动/属性。
2. **任务平面**：`POST /datasources/{id}/test` 与 `/sync` 返回 202 JobDTO，
   `GET /jobs/{id}` 查询；SYNC 入队 `metadata_sync_job` 后由单线程 runner 执行，
   成功才原子发布快照，失败不发布；TEST 复用 V6 `job_type` 记录终态行，
   草稿凭据只在内存中参与探测、绝不落库。Job `progress.total` 未知时为 null。
3. **元数据与字典**（`local.ptmcp.admin.metadata`）：对象列表/详情只读取
   `requireUsableActiveSnapshot` 通过的已发布快照，支持 namespace/kind/keyword 过滤与
   `(object_norm,id)` 游标分页；详情返回列与字典；字典 `PUT` 需 If-Match，版本取
   `COALESCE(MAX(version),1)` 聚合并整体替换，未知列/富文本/控制字符/重复列拒绝，
   只写注释不触达业务库 DDL。
4. **幂等与错误**：新增 POST 全部要求 Idempotency-Key（C5 `IdempotencyRecorder`），
   相同 key 重放原响应并带 `Idempotent-Replay: true`，相同 key 不同 body 422；
   `ApiExceptionAdvice` 将领域错误与 Spring 绑定失败统一为
   `{code,codeNumber,retryable}` 稳定外壳，驱动栈不外泄。

不做：R<T> 响应封装（协调者统一替换）；数据源列表/对象列表的签名不透明游标与
`CURSOR_STALE`；委派管理员范围（当前仅平台管理员）；连接池运行时预算与多副本调度；
成功 TLS 业务库连通性的正向夹具。

## 偏差

- **422 语义**：poolMax 越界、未知字典列、富文本在实现中返回 400 INVALID_ARGUMENT；
  api-spec §1 将业务约束归 422，但 `ErrorCode` 稳定码表当前仅有
  IDEMPOTENCY_KEY_REUSED 映射 422，未新增错误码以免跨模块契约漂移，待统一错误码表时收敛。
- **TEST 同步执行**：探测在请求线程内完成并返回 202 终态 TEST job，便于草稿凭据绝不落库；
  HTTP 时延包含 3s 登录超时，未做后台异步（避免凭据随任务持久化）。
- **健康状态**：列表/详情 `health` 固定 `UNKNOWN`，无独立健康检查模型。
- **R<T>**：仍为显式 DTO 直出，待协调者统一上游 R<T> 替换。

## 交接

- **游标**：数据源列表用数字 id 游标，元数据用 base64(`object_norm\nid`)；
  均未签名、未绑定筛选哈希/主体/有效期，无 CURSOR_STALE；按当前分页约定实现，
  待统一游标组件替换。
- **管理范围**：/admin 数据源/元数据端点仅 `requirePlatformAdmin`；委派管理员的
  服务端范围校验尚未接入（T16-a 已提供 SelfEscalationGuard 等基础）。
- **DNS 重绑定**：连接前对域名解析结果做白名单校验，但解析与建连之间未固定 IP；
  已拒绝空/多地址越界，完整 pinning 需驱动层定制。
- **成功路径缺口**：受信 CA 下 `VERIFY_FULL` 探测/同步成功、快照发布后的端到端对象可见性
  尚未在本片覆盖；B5 已有快照发布独立测试，接入前端前需补一个可信证书业务库夹具。
- **前端接口**：数据源/元数据/字典/任务端点 DTO 已可直接对接，R<T> 替换会改变外壳，
  前端适配时以届时契约为准。
