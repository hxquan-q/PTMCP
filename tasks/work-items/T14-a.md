## 目标与边界

来源/父任务或用户请求：[parallel-prompts-20261024](../parallel-prompts-20261024.md) C4，父任务 T14；
[认证设计](../../docs/backend/authentication.md) §3/§8、[安全架构](../../docs/architecture/security.md) §5、
[API 规格](../../docs/backend/api-spec.md) §9、TC-API-007、TC-AUT-008/009。

实现 `ptmcp-authz` 模块 `local.ptmcp.authz.platform` 包下的平台信任原语（TDD，先测后码）：

1. **Tier1 逐请求证明**（authentication.md §3/§8、security.md §5）：`PlatformProof` 承载每请求观测到的
   证明材料（平台绑定、证明类型、mTLS 指纹或代理共享密钥、来源地址）；`MtlsProofVerifier` 按平台指纹
   白名单校验（缺失 → `PLATFORM_PROOF_REQUIRED`，不匹配/未登记 → `PLATFORM_MISMATCH`）；
   `ProxySecretProofVerifier` 要求来源地址落在代理 CIDR 白名单内且常量时间密钥匹配。
2. **DCR 公开客户端注册**：仅 `none` 认证方法、scope 封顶 `mcp:catalog`、自认平台绑定/内部客户端
   标志一律拒绝；重定向 URI 结构校验（https 精确源；仅回环允许 http；禁 fragment/userinfo/通配符/
   父目录穿越；1..5 条）。
3. **CIMD/SSRF 防护**：`CimdPolicy` 纯函数墙（仅 https/443、禁止 userinfo/fragment；所有解析地址
   必须公网可达——回环/RFC1918/ULA/CGNAT/链路本地/组播/云元数据全部拒绝，无业务数据源私有网段
   例外）；`CimdResolver`（IP 字面量不触 DNS 直接校验、主机名走注入 DNS、32KiB/深度 8 预算、按 URL
   缓存带 TTL、重定向映射 `INVALID_ARGUMENT`、DNS/非 200 失败 `DEPENDENCY_UNAVAILABLE`）；
   `CimdHttpFetcher`（JDK HttpClient，从不跟随重定向，仅 2xx + application/json，流式 32KiB 截断）。

不做项：不接 HTTP 端点/网关接线；不实现 refresh 轮换（D1）；不改 B4 OAuth 流程断言；不改共享契约。

（重定向不跟随、非 JSON、404、超限、200 JSON）直接测 `CimdHttpFetcher`。

  Could not find a valid Docker environment，失败均为不同用例且单跑即绿，已按环境抖动处理，
  未改任何断言）。
- RED 证据：实现类缺失时 `mvn -pl ptmcp-authz -am test-compile` 67 个编译错误（真实失败先于实现）。
- 错误映射依据：`PLATFORM_PROOF_REQUIRED`=证明缺失；`PLATFORM_MISMATCH`=证明错误/未登记平台/
  证明类型不符；`UNSUPPORTED_FIELD`=DCR 越界 scope；`INVALID_ARGUMENT`=DCR 自认绑定、URI 结构
  违规、CIMD URL/地址墙违规、JSON 解析/深度超限、重定向；`METADATA_TOO_LARGE`=>32KiB；
  `DEPENDENCY_UNAVAILABLE`=DNS 失败、非 2xx、网络/超时。
- 已知限制（报告项）：JDK HttpClient 无公开套接字级地址绑定 API，`CimdHttpFetcher` 以 resolver 层
  策略墙（URL+全地址校验+IP 字面量直连）作为 SSRF 主防线，`pinnedAddresses` 参数保留在接口上供
  连接器层绑定；套接字级 pinning 在网关接线切片落地。另记录：B4 既有 `fullCodeFlowIssues...`
  用例出现过一次 600/599 跨秒边界抖动（重跑即绿），建议后续放宽该计时断言。
