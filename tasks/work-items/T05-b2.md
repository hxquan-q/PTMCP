## 目标与边界

父任务 T05；来源 sql-guard §3/§5、总体方案 §8、FR-14、TC-GRD-011/013、ADR0004。目标是在 AST 上以"正向白名单"拒绝未审函数、路径函数、非基础 CAST 类型及系统命名空间关系，作为 T05-b1 语句形状门禁之后的第三道静态拒绝。

白名单为初期候选子集，**未列入即拒绝**：COUNT/SUM/MIN/MAX/AVG/ABS/ROUND/LOWER/UPPER/LENGTH/COALESCE/NULLIF/ROW_NUMBER/RANK/DENSE_RANK/EXTRACT。路径函数（`public.fn()`、`mydb.fn()`）一律拒绝；CAST 目标仅允许基础标量类型集合，带路径或不在集合内一律拒绝；关系名的 catalog/schema 位置命中 `information_schema`/`mysql`/`performance_schema`/`sys`/`pg_catalog`/`pg_toast`，或对象名以 `pg_` 开头即拒绝。

不做：只读表达式推导、输出类型/宽度计划、每方言函数签名与返回类型版本化数据、系统函数/临时 schema 的完整方言矩阵、关系存在性与授权、绑定与改写、ApprovedQuery、JDBC/HTTP。未逐节点分派全部未知表达式类型——该职责在作用域绑定/表达式白名单阶段（T06/T07）仍需显式遍历；本片不声称 TC-GRD-013 全量通过。

## 实施与验证

新类 `guard.ast.SqlAllowlistGate`：解析单一 SELECT 后，用 `SelectVisitorAdapter` + `ExpressionVisitorAdapter` 组合遍历；表达式 visitor 的 `visit(Function)`、`visit(CastExpression)` 与 `visit(Select)` 分别执行函数白名单、CAST 类型白名单和嵌套 SELECT 递归。两条 visitor 通过显式 `Link` 对象双向连接（构造时注入），避免依赖"稍后 setter"的隐式装配。FROM 项按类型判定，未知 FROM 类型 fail-closed。

先写测试。真实失败序列（全部保留在 `.local/verification/t05-b2-*.log`）：首轮 18 项失败——visitor 未真正进入表达式，`sleep()`/`load_file()`/CAST/系统表全部漏过；改为构造期注入 Link 后函数与 CAST 生效；第二轮 6 项失败——两段名 `mysql.user` 的 schema 位置未纳入系统命名空间集合，统一为 `SYSTEM_NAMESPACES` 同时检查 catalog 与 schema；第三轮 2 项失败——`DECIMAL(18,2)`/`VARCHAR(64)` 的 `getDataType()` 含精度参数，改为取 `(` 前基础类型。没有放宽任何拒绝或删除断言。

## 结果与证据

`.\mvnw.cmd -B -ntp -pl ptmcp-guard -am test` 退出 0：guard 141 项（本片 31、语句形状 34、词法 74、策略 2），common 194 项，0 失败/错误/跳过；日志 `.local/verification/t05-b2-tests6.log`。

覆盖：允许的聚合/字符串/数值/窗口函数与两类带精度 CAST；拒绝 `sleep`/`pg_sleep`/`load_file`/`pg_read_file`/`nextval`/`CONCAT`/`GROUP_CONCAT`/路径函数，且嵌套子查询与派生表内的危险函数同样拒绝；拒绝 `CAST(... AS public.leaky_type)`、`AS uuid`、`AS mydb.custom_type`；拒绝 `mysql`/`information_schema`/`performance_schema`/`sys`/`pg_catalog` 限定关系、`pg_authid` 保留前缀及 JOIN 中的系统表；非 SELECT 与多语句先于白名单拒绝；解析失败只返回 `SQL_SYNTAX_INVALID`，不回显输入。

作者自审：正向白名单（默认拒绝）而非黑名单；无新增依赖；无 public 执行入口或 ApprovedQuery；错误仅含登记错误码。限制：函数签名/返回类型与方言差异未做；宽行聚合函数仍整体拒绝（fail-closed）；本层通过不表示可执行或已授权。评审为作者自审 + 真实单测，无独立安全评审，不代勾 T05 父任务。
