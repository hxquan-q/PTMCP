## 目标与边界

来源/父任务：T16 父任务；[API 规格](../../docs/backend/api-spec.md) §5（/acl/matrix）、
T16-a（ACL 管理与自增权守卫）、T16-b（委派管理员）工作项。

实现授权矩阵查询与有效权限展示：

1. **`AclGrantStore.matrix`**（persistence/org）：授权矩阵查询，全部过滤（subjectType/
   subjectId/resourceType/resourceId/status/effect/stale/limit）在 SQL 内完成；每行输出
   effect、有效期窗口、授权 version、resource_generation、**live generation**（按资源类型
   关联 datasource.config_version / resource_namespace.generation /
   resource_object.generation）与 **stale 标志**（generation 不匹配=资源删除重建后旧授权）。
2. **`AclMatrixController`**（admin/api 新增）：GET /api/v1/admin/acl/matrix；平台管理员
   全量可见；委派管理员必须钉定 resourceType+resourceId 且委派覆盖 acl:list 动作，否则
   403（IDOR 防护——未范围化的矩阵请求不返回任何行）。
3. **代际失效**（AclDirectory.activeGrants）：SQL 增加资源代际校验（与 live generation
   不匹配的授权不再参与 preview/有效权限判定）——资源删除重建后旧授权自动失效。
4. 不做：审计管理 API（T16-d）；guard OutputPlan 来源（T07-c）；审计事件外发。

## 实施与验证

- persistence：`AclGrantStore` 新增 MatrixRow/matrix 查询（过滤全部在 SQL 内、LIMIT 上限
  500）；`AclDirectory.activeGrants` 增加代际失效子查询。
- admin：`AclMatrixController` 新增；`ManagementScope.requireGrantOperator` 委派门的
  targetSubjectDeptId 语义修正为「null=无主体子树维度」（矩阵查询无目标主体，只按资源+
  动作门控）；DelegationStore 清理 T16-b 遗留调试 printStackTrace。
- `AclMatrixApiTest`（新，MockMvc + 真实 MySQL 8.4 容器，6 例）：
  1. 矩阵展示 ALLOW/DENY/窗口/版本/generation/liveGeneration/stale；effect/status/subject/
     resource 过滤均在 SQL 层生效（ALLOW-only 无 DENY 行、REVOKED 为空、resource 不匹配为空）。
  2. Deny 覆盖 Allow + 主体版本变化：READ ALLOW→preview read=true；追加 READ DENY→read=
     false；用户获得角色（role META grant）→meta 翻转 true 而 READ deny 仍然保持。
  3. 子树继承：NAMESPACE 级 include_descendants 授权覆盖子 OBJECT（preview read=true）。
  4. 资源删除重建：config_version 1→2 → 矩阵 stale=true+liveGeneration=2+旧 generation=1、
     非 stale 查询为空、preview read=false（旧授权不再生效）。
  5. 委派管理员 IDOR：未钉定资源 403；钉定范围内资源仅见该资源行（无 datasourceB 泄漏）；
     钉定范围外资源 403；平台管理员全量可见。
  6. 跨部门：委派管理员对委派子树外部主体授予 → 403 MANAGEMENT_SCOPE_DENIED。

## 偏差

- 矩阵查询的 live generation 以 SQL CASE 子查询逐类型关联（datasource.config_version /
  resource_namespace.generation / resource_object.generation），与 AclGrantStore 既有
  代际校验语义一致；未引入新的资源身份抽象。
- 委派管理员矩阵查询要求显式 resourceType+resourceId（无全局未范围化矩阵），未范围化
  请求 403 而非空集，避免跨范围行存在性泄露。
