## 目标与边界

来源/父任务：T09 父任务；[审计设计](../../docs/backend/audit.md) §4/§5、
[数据库设计](../../docs/backend/db-design.md) §6、现有 AuditRepository/TerminalWal/WalPayload。

实现 `ptmcp-persistence` audit 领域新增 `masking` 包，供执行链（T10/T19）与审计查询
（T16-d）调用：

1. **AST 受控脱敏**（`AuditSqlMasker`）：以 JSqlParser（与 guard 同源、父 POM 版本管理）
   的成功解析为结构 oracle；掩码投影由受控词法变换生成——字符串/数字/hex/bit/日期时间
   字面量全部替为 `?` 占位符，注释（`--`/`#`/`/* */`）删除、空白规范化，作用域覆盖 SELECT
   投影常量、CASE、CAST、IN 列表等全部位置而非仅 WHERE。掩码文本必须**再次通过解析**且
   存活字面量扫描为零，否则整体降级 hash-only，绝不回退部分脱敏明文。
2. **降级语义**：解析失败（PARSE_ERROR）、掩码后存活字面量（LITERAL_REMAINS）、掩码再解析
   失败（MASKED_REPARSE）、输入 >64KiB UTF-8（SQL_TOO_LARGE）或含 NUL（NUL_BYTE）时只输出
   SHA-256 指纹 + UTF-8 长度 + 降级码 + 规则 ID（AUDIT-MASK-001..005）；`MaskedSql.toString()`
   不含任何 SQL 片段。指纹绑定 schema 版本 + 方言 + 资源身份 + 规范化掩码文本。
3. **字段信封加密**（`SqlFieldCipher` + `SqlFieldCipherPolicy`）：sql_raw/sql_final 仅在策略
   enabled 时 AES-256-GCM 加密；数据密钥复用 WAL 的 `WalKey`（KMS 侧职责不变）；每信封独立
   96-bit 随机 nonce；AAD 绑定部署/租户标识 + 字段名 + requestId + schema 版本；输出
   `[u8 schema][12 nonce][cipher]`，key_id 由调用方落 `audit_log.key_id`。禁用策略两个方向
   都返回 null（"未存储"语义），disabled+非空 deploymentId 构造即拒绝。加密输入 >64KiB、
   含 NUL、空字节组、未知字段名一律 INVALID_ARGUMENT 拒绝；解密任何失败（篡改/绑定不符/
   截断/版本未知）一律 AUDIT_UNAVAILABLE，调用方保持安全终态。
4. **不新增敏感通道**：结果行/token/密码/连接串/异常栈没有任何参数入口；本包不做日志输出。

不做：`AuditRepository`/`TerminalWal` 行为变更（列已存在，调用方接线归 T10/T19-b）；
outbox/消费者语义；Loki/ELK 外发；掩码粒度的资源级访问控制（T16-d 的 decrypt 审计面）。

## 实施与验证

- 新增 `masking/AuditSqlMasker`、`MaskedSql`、`SqlFieldCipher`、`SqlFieldCipherPolicy`；
  `ptmcp-persistence/pom.xml` 新增 `com.github.jsqlparser:jsqlparser`（版本走父 POM 管理，
  与 guard 同源；未改父 POM）。
- 已知取舍（记录于类注释）：字面量掩码按词法边界执行（标识符 `t1` 中的 `1` 不会被当作
  数字）；空语句不可解析，按 PARSE_ERROR 降级；INTERVAL 等掩码后无法再解析的语法自动走
  MASKED_REPARSE 降级；`MaskedSql` 故意不支持内容 equals（指纹不可当值对象比较）。

### 测试（纯 JVM，无容器依赖；容器回归由既有 audit 测试族覆盖）

`AuditSqlMaskingTest`（7 例）：SELECT 投影/CASE/CAST/IN/注释全量脱敏（断言原始值、注释、
hex 均不残留、占位符存在）；指纹绑定方言/资源身份且稳定；解析失败 hash-only 且 toString
无原文泄漏；INTERVAL 类不可证明语法自动降级；>64KiB 与 NUL 降级；空语句降级 + 参数化语句
安全通过（标识符 `t1` 不被误掩）；构造/入参非法拒绝。
`SqlFieldCipherTest`（5 例）：往返 + AAD 四维逐一绑定（requestId/field/deployment/密钥）；
篡改/截断/空信封拒绝；100 次加密 nonce 零复用且信封全异；密文不含明文（字节+ASCII 扫描）；
禁用策略 null 语义与构造拒绝；64KiB 边界/NUL/未知字段拒绝、null 透传。
