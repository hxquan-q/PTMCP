## Destination

本周内形成面向客户的立项判断：用真实 MES 数据跑通端到端闭环，证明技术可行性，支撑客户决定做/不做、投入多少、何时交付。

## Notes

**已确认约束**

- 拍板人：客户；硬期限：本周内。
- 客户可提供只读库账号。
- 客户认的“技术可行”：真实数据跑 20–30 条基线题；证据优先级为真实数据跑题 > 端到端 Demo > 架构/安全文档。
- 只证一件事：自然语言 → 官方口径/VQ → SQL → 结果 → 证据 → 审计的端到端闭环。
- 复用 PTMCP 现有身份、只读 guard、审计和执行器；不重写。
- 管理面只对管理员开放；自由 SQL 默认关闭，仅管理员白名单开启。
- 立项材料必须区分“已验证 / 未验证”；演示不等于客户验收。

## Not yet specified

- 客户真实 MES 数据的表范围、行数、刷新频率与口径文档是否齐全。
- 客户业务专家能否在本周参与答案键签字；不能时谁代签。
- 客户是否要求演示在其内网/离线环境进行；若是，网关安装与镜像准备是否来得及。
- 客户对“端到端”的最小期待是否包含客户自己的 Agent 客户端。
- 立项后的完整一期范围（6–8 周）是否需要在本次决策会上同时确认。
- 报价/合同条款是否进入本次立项判断（当前按“技术可行性”处理，不展开商务）。

## Out of scope

- 完整一期交付（6–8 周）的实施与验收。
- WMS/ERP 领域包、多领域路由。
- 多级管理员、普通用户自助配置/发布/升级。
- MCP Tasks/Apps 扩展、A2A 行动服务。
- 正式生产部署、客户环境长期运维、商业报价与合同条款。
- 通用 Agent 运行时或替代客户现有 Agent 客户端。
