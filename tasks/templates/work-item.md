# 工作项模板

复制正文到 `tasks/work-items/<ID>.md`，替换值并移除此说明。实际记录第一行标题包含 ID；`ID` 与文件名一致。占位内容不是证据，不能带着占位符标完成。

```markdown
# T01-a：一个可验证目标

ID: T01-a
Status: draft
Owner: current-agent
Acceptance: pending
Verification: NOT_RUN
Updated: YYYY-MM-DD

## 目标与边界

来源/父任务或用户请求：
目标、当前与期望行为（Given/When/Then）：
不做项、不变量、兼容/安全边界：
已有修改和所有权：

## 实施与验证

依赖、读写路径、独占契约：
串行/并行结论及负责人；并行时记录授权和工作区：
当前切片、失败/基线、实施和回滚/收窄路径：
验收标准、实际存在的验证命令/环境；缺失条件标明：

## 结果与证据

实际修改、命令/退出码、覆盖行为和证据路径：
未执行项及原因、剩余风险：
评审类型（自审/独立）、发现与修复：
人工接受来源；内部任务不适用时说明原因：

## 交接

当前焦点、剩余项和下一步：
实际 git status、提交/集成/发布事实：
已有授权与待决定事项：
```
